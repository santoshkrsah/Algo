ROC indicator (monthly)

ROC = (is mahine ka close / N mahine pehle ka close - 1) x 100. Laal line = sell level (Nifty 45, Smallcap 100), hari = 0 (buy). Shaded = state OFF (stock strategies me naya trade nahi).
